# Rubro Tecnologia Site

Projeto React + Vite + Tailwind do site institucional da Rubro Tecnologia.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Estrutura
- `src/App.jsx`: página principal
- `src/components/ui`: componentes básicos usados no layout
- `src/index.css`: estilos globais com Tailwind
